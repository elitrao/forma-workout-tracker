# FORMA Workout Tracker

Локальный персональный трекер тренировок Даниила.

## Аккаунты

- Регистрация с именем, логином, паролем и выбором аватара.
- Рост, текущий и целевой вес сохраняются в профиле.
- У каждого профиля отдельная история тренировок и замеров.
- Пароль хранится локально в виде солёного хеша, а не открытого текста.

> Аккаунты работают только в текущем браузере. Для синхронизации между устройствами нужен серверный backend.

## Запуск

```powershell
python -m http.server 3004 --directory dist
```

Локальный адрес: http://localhost:3004/
