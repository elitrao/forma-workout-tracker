# FORMA Workout Tracker

Персональный трекер тренировок Даниила с локальным сервером и SQLite-базой.

## Аккаунты

- Регистрация с именем, логином, паролем и выбором аватара.
- Рост, текущий и целевой вес сохраняются в профиле.
- У каждого профиля отдельная история тренировок и замеров.
- Регистрации и тренировочные данные хранятся в `data/forma.sqlite`.
- Пароль хранится как солёный `scrypt`-хеш, а не открытый текст.
- Авторизация работает через защищённую `HttpOnly` cookie-сессию.

Файл базы не попадает в Git. Для резервной копии достаточно сохранить `data/forma.sqlite` при остановленном сервере.

## Запуск

```powershell
npm start
```

Требуется Node.js 24 или новее.

Локальный адрес: http://localhost:3004/
